# 资料包说明｜P3 会话操作弹窗

这是用户从同轮三个设计结果中明确选定的 **P3（第三张）**，不能使用此前 P1/P2 的菜单项目替代它。

## 图片优先级

- `01_P3会话操作弹窗_唯一视觉基准.png`：**唯一授权的弹窗视觉标准**，包括宽高比例、六行文案、图标、细线边框、间距、颜色、阴影与圆角。
- `02_P3弹窗局部_核对用.png`：从 P3 原图原像素裁切的局部视图，用于看清菜单细节，**不是第四版设计**。
- `03_现有聊天界面_背景与功能基准.png`：用户当前运行截图，优先决定**弹窗以外**的原有侧栏、好友名单、会话、登录身份、库存图标与按钮位置。不要按 P3 生成图中可能存在的示意数据重构背景。

### 若图片冲突
弹窗本身以 `01` 为准，页面其余现有内容以 `03` + 当前项目实际代码为准，动态用户数据永远从真实登录会话读取。

## 特别留意 P3 确切六项

1. 查看资料 — 查看对方的公开资料
2. 修改备注 — 设置备注名，方便识别
3. 标记卡牌 — 为该好友设置卡牌标记
4. 与此好友的记录 — 查看赠送、交换等历史记录
5. 屏蔽此好友 — 不再接收对方的消息
6. 删除好友 — 删除后将不再显示在好友列表中

禁止替换成“赠送好友”“与此好友换卡”“消息免打扰”“举报用户”等此前草图的菜单文案。外部会话顶栏已有功能保持原位。

具体执行要求参见 `04_会话操作_P3_Codex执行提示词.txt`。
