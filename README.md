# HEBUTZZ
河工开物开发

学习工作台现为唯一首页：打开根目录 `project.godot` 后按 **F5** 运行。左侧可进入总题库、错题库、河工开物、我的收藏。右侧横幅、四张统计卡片和题型分布只展示内容，原点击跳转及详情页已移除；仅“学习趋势”可以打开学习记录。横幅的开始 / 继续学习按钮已移除，答题从侧栏总题库或错题库进入。没有悬浮说明。仍支持 F9 切换深浅色、Ctrl + 滚轮调整字号和窄窗口滚动。全软件滚动条由 `UiResources` 统一隐藏，包括编辑器、弹窗和菜单内部的滚动条；保留滚轮、触摸及原有键盘滚动行为。

Esc 统一返回上一层：先关闭当前弹窗、下拉菜单、展开的资源预览或窄屏题号浮层；卡牌详情返回收藏总览，文章详情返回河工开物列表，答题页返回对应的总题库或错题库，各一级页面返回工作台，工作台不再跳转。返回时沿用题库/资源列表的筛选与滚动位置，长按不会连续跨层；页面“返回”按钮与 Esc 使用同一个入口，“结束练习”仍直接结束并返回工作台。专项检查：`python tools/run_workbench_checks.py --godot <Godot控制台程序路径> --script check_back_navigation.gd --visual`。

本轮外观以用户提供的“高清重绘版/简约风”整套设计为准：首页、总题库、错题库、河工开物、答题页与收藏空页共用 `scripts/minimal_page.gd` 的字体、字号、按钮尺寸、图标尺寸和颜色规范。首页使用白底、细分隔线与横向题型进度条，不再显示横幅插画。品牌继续使用用户原有河流标志。

答题页的题号列表位于右侧，支持点击题号、输入跳转和单独隐藏；窄窗口按需从右侧展开。“解析”和“标记”按钮已移除，题号列表仅保留当前题、已答、未答三种提示。答题时按 **F6** 隐藏左侧导航与顶部返回/课程标题/计时/结束练习栏，答题区自动扩展，再按 **F6** 恢复。长按不会反复切换，填空框和代码编辑器聚焦时也有效；题目、答案、草稿、计时及题号列表的展开状态均保留。F6 仅作用于当前答题页，新开练习恢复普通布局；F9 切换主题和 Ctrl + 滚轮缩放不退出专注布局。

页面加载采用五项优化：`UiResources` 共用字体、主题和图标；题号列表按可见区域复用按钮；答题场景仅保留实际使用的控件；`StudyStats` 统一读取、校验并缓存题库，练习只复制题目列表；`PageRouter` 保留侧栏及最多 4 个非当前常用页面。总题库与错题库分别缓存，保留筛选和滚动位置，返回时刷新学习记录与错题；答题会话不缓存，新开练习仍创建新会话。题号聚焦时可用方向键、Home/End、PageUp/PageDown 移动，Enter/空格选择。

加载回归：`python tools/run_workbench_checks.py --godot <Godot控制台程序路径> --script check_loading_optimization.gd`。同一命令换为 `--script profile_page_switches.gd --visual` 可记录首次及重复进入的资源加载、页面构建和首帧间隔；比较时关闭其他测试进程。缓存数量可在 `scripts/page_router.gd` 的 `CACHE_LIMIT` 调整，默认 4，不包含当前页面。

普通答题模式使用题干 26、选项 24 的基础字号，F6 专注模式使用题干 28、选项 24，题号列表字号不变。两种模式的题干均按内容占高，选项基础高度 56、间距 24；答题区高度不足 650 时改为高度 48、间距 16。多行题干和选项会自动增高，长题仍可滚动，Ctrl + 滚轮仍可整体缩放。字号参数位于 `scripts/minimal_quiz_view.gd` 顶部的 `QUESTION_FONT_SIZE`、`OPTION_FONT_SIZE` 及两项 `FOCUS_*` 常量，按钮尺寸和间距位于 `_apply_question_typography()`。加入错题库按钮始终保持页面底色；未加入时文字与图标使用普通颜色，已加入时固定为蓝色（深色模式使用浅蓝），悬停、聚焦和按下不会改变这个状态颜色。该反馈通过 `state_only_feedback` 单独启用，不改变其他按钮的样式。

已提交的题目再次点击题号或切回来时可重新作答，旧选择、输入和参考答案会清空，题号列表仍保留“已答”记录；未提交的选择和输入保留为草稿，编程题草稿也继续保留。再次实际提交会记一次作答，停留在当前结果上重复点击提交不会重复计数。F6、主题切换和窗口调整只改变显示，不开始新一轮作答。“结束练习”直接返回工作台。

图标素材位于 `assets/minimal/icons/`，每个图标单独导出为 384 × 384 透明 PNG，按参考选择原始线性图标轮廓，源文件、授权及导出工具均随项目保存；选中工作台仍复用原有实心房子图标。文字全部使用原生控件，采用 4 倍字体过采样，图标开启 mipmap 缩小过滤。界面现使用统一、可中断的颜色与透明度过渡，不使用循环装饰、卡片缩放、导航位移或悬浮说明。

总题库提供课程/题干搜索、课程类别和学习进度筛选。错题页读取原错题 ID，支持科目筛选、已练习/未练习筛选；“待复习错题”使用与总题库一致的课程卡片，只展示有匹配错题的科目，显示该科目的错题总数和已练习比例，可开始/继续复习。逐题列表和“查看全部错题”入口已移除。旧错题没有逐题日期和错误次数，因此不伪造示意图中的日期、次数与掌握度，趋势展示新版记录的每日答错次数。河工开物继续使用现有四条示例资源，已移除“默认 / 名称 / 分类”排序，按数据源顺序显示；搜索、分类、示例展开、正文和公告均保留。答题页通过 `scripts/minimal_quiz_view.gd` 共用外观，判题、错题存档、Python 运行和草稿仍由原控制器负责。

旧首页场景、脚本和入口已删除。各功能的返回首页按钮统一返回工作台。唯一首页为 `scenes/Workbench.tscn`，界面逻辑为 `scripts/workbench.gd`。“我的精灵”入口已替换为“我的收藏”：`scenes/MyCollection.tscn` 和 `scripts/my_collection.gd`；原有答题经验和存档没有清除。

收藏支持按系列展开、筛选和查看卡牌详情。卡片网格上下排间距缩小 5px；详情操作文案为“想要”，标记后仅在列表卡牌图片右下角显示蓝色实心心形，不新增文字行或改变卡片高度，取消后移除心形。详情页左侧在常规桌面宽度下每行展示 4 张卡片，较窄窗口自动减少列数；卡名右侧同行显示真实数量（如 `×3`），未知数量显示 `×—`，已知未拥有显示 `×0`。总览与详情共用紧凑的顶部布局，已删除“返回收藏”按钮及空白工具栏占位；详情按 Esc 返回总览。系列展开图标使用独立的 `assets/minimal/icons/collection-chevron.png` 素材，展开/收起旋转 90°，时长由 `ui_tokens.gd` 的 `CHEVRON` 控制（0.16 秒），减少动态效果时直接显示最终方向。

学习工作台读取六门课程的真实题库数量，当前合计 **2,981 题**。新增学习记录独立保存在 `user://workbench_study_v1.json`：每日题数按课程和题号去重；提交答案或查看编程题参考代码记为已学；累计天数仅统计实际学习的日期；继续学习按题号恢复位置。旧存档没有日期及题号明细，因此每日记录和进度从使用新版起统计，不倒推历史数据。原错题、精灵经验和 Python 草稿继续使用原存档。

工作台检查：`python tools/run_workbench_checks.py --godot <Godot控制台程序路径> --visual`。使用独立存档，覆盖唯一首页启动、展示区无点击入口、学习趋势记录、课程跳转、统计去重、编程题复习、收藏空页及返回、深色和窄窗口布局；最新截图保存在 `outputs/minimal-design/`。整套页面检查：同一命令添加 `--script check_minimal_design.gd`。视觉核对记录见 `design-qa.md`。

动效与工大蓝的唯一参数文件是 `scripts/ui_tokens.gd`；`scripts/ui_motion.gd` 管理 Tween 的替换、销毁清理和系统偏好，`scripts/ui_feedback.gd` 管理按钮、输入框、卡片的组合状态。主色为 `#092C87`，hover 为 `#092A80`，pressed 为 `#08287A`，选中浅底为 `#EBEEF5`。当前时长（毫秒）：press 80、hover 140、state 120、tab underline 700、panel/page 180、exit 120、data 1700、reward 400、pet ≤500。Godot 使用无回弹 cubic ease-out/ease-in 等效缓动；当前没有新增奖励或精灵动画。

页签下划线：总题库的课程分类、河工开物的资源分类，以及错题库的“全部错题 / 未练习 / 已练习”均在点击后从中间向两侧展开。当前沿用用户调整后的 **700 毫秒**，先快后慢，无回弹。修改 `scripts/ui_tokens.gd` 中的 `const TAB_UNDERLINE := 0.70`，保存后重新运行即可；单位是秒，`0.40` 为 400 毫秒（更快），`1.0` 为 1 秒（更慢），`0.0` 则立即显示。重复点击会重新展开，快速切换会取消旧动画；只有下划线横向展开，文字与按钮点击区域不动。首次进入、主题重建直接显示完整选中线，系统减少动态效果设置仍有效。

按钮和搜索框聚焦时保持原有内部底色，仅显示边框反馈。统一关闭焦点阴影叠色，关闭、取消等浅色按钮不再出现灰蓝色填充，浅色和深色模式均适用；搜索与清除、筛选逻辑不变。学习记录的 14 个日期条目仅展示日期和题数，不可点击或键盘选中，已移除日期详情与点击提示；关闭按钮、遮罩关闭及 Esc 仍可正常使用。

选择框：总题库的学习进度筛选和错题库的科目筛选共用 `_style_choice`，统一边框、圆角、留白和交互状态。原生下拉菜单明确使用页面的 4 倍过采样字体、字号与深浅色主题，箭头和选中标记使用矢量图标，避免菜单回退到引擎默认字体及深灰底色。保留原生键盘选择、关闭与焦点行为。

错题趋势按所选科目分别统计近 7 天的答错次数；“全部科目”显示合计。切换科目必定重新播放 0.70 秒的折线/圆点展开，即使两个科目的数值相同。每日记录在原存档文件内新增 `subjects` 计数（格式版本 2），重复答错按次累加，查看参考代码不算答错。旧记录只有当天全部题目属于同一科目时才能准确归属；混合科目的旧总数继续保留在“全部科目”，不猜测拆分，并在单科目图表中提示统计口径。专项检查添加 `--script check_choices_and_wrong_trends.gd --visual`，覆盖保存/重载、独立曲线、重播、选择框主题与放大显示。

趋势图与进度条：学习趋势、错题趋势的折线及圆点按从左到右依次显示；学习进度、题型/课程分布、总题库和错题课程卡片的实色填充从左向右展开。共用 `scripts/ui_tokens.gd` 的 `const DATA := 1.70`（秒）。进入可视范围时播放一次，数据改变或筛选生成新内容时重新播放；缩放窗口和已完成内容的滚动不重复播放。坐标轴、文字、真实进度值保持不动，灰色底轨保留。公共 `ui_data_reveal.gd` 使用布局/滚动事件触发，无逐帧可见性轮询；`ui_progress_bar.gd` 只控制绘制的填充宽度。减少动态效果立即显示最终状态。验证命令添加 `--script check_data_reveal.gd --visual` 可检查中间帧、滚动触发及真实数据不变。

减少动态效果：启动时和窗口重新获得焦点时读取 `DisplayServer.accessibility_should_reduce_animation()`。返回 `1` 时关闭全部 Tween，`-1` 表示系统能力未知（例如 headless），不会宣称已取得系统偏好。统一接口 `/root/UiMotion.set_enabled(false)` 可立即结束现有过渡并直接显示最终状态；启动前设置环境变量 `HEGONG_REDUCED_MOTION=1` 也可关闭，不新增设置页面。触屏输入关闭 hover，真实鼠标输入恢复；失焦/隐藏时完成视觉过渡并暂停答题计时标签刷新，计时基准保持不变。

## 个人中心（2026-10-27）

公共侧栏左上角现为头像、显示名称和“个人中心”入口，替换原品牌区；侧栏宽度、导航坐标和第四项“河工开物”资源入口保持不变。未登录显示“登录”，当前仓库没有正式登录服务，因此点击会进入个人中心并明确说明服务尚未接入。品牌素材、应用名称和启动场景保留。收藏导航与个人中心收藏快捷入口使用同一个卡牌图标、场景路由和 `CollectionStore`，不重置收藏页缓存、筛选或分季展开状态。

`scenes/PersonalCenter.tscn` / `scripts/personal_center.gd` 实现上方身份、下方左侧资料和右侧设置布局；窄窗口顺排并滚动。右侧只有“账号与安全”“我的收藏”和轻量“版本信息”，底部保留退出登录。`profile_dialog.gd` 提供编辑、好友、账号、版本和登录/退出局部面板，使用原字体、主题、工大蓝、动效和原生独占窗口焦点。`profile_identity.gd` 是可跨页面保留的身份按钮；`profile_avatar.gd` 及 `assets/profile/`、`shaders/profile_avatar.gdshader` 负责圆形等比裁切、失败回退和局部线性图标。

`ProfileStore` 自动加载项是统一资料状态与服务适配层，不是新账号系统。仓库没有正式认证、个人资料保存、头像上传、账号绑定或退出接口，也没有正式好友服务；当前不会产生示例用户、随机 ID、虚假保存或虚假退出。好友面板复用收藏赠送的 `request_friends` 数据源，当前缺少好友服务时明确提示。版本信息读取 `application/config/version`；当前项目未提供该值，显示“当前构建未提供版本号”，没有套用 Android 导出配置或引擎版本冒充桌面应用版本。

后续真实服务接入契约（服务负责身份校验、字段权限、格式验证、持久化、请求超时及现有账号流程）：

- 已验证的会话由宿主调用 `ProfileStore.use_provider(adapter, {state: "authenticated", account_id: existing_account_id}, collection_adapter)`；初始未知会话用 `state: "loading"`，确认退出用 `state: "signed_out"`。资料加载失败不改变会话。切换会话同步清空旧资料并使旧请求失效；收藏继续使用已有账号分区机制，不删除存档。如果一个适配器同时实现收藏接口，可省略第三个参数。
- `request_profile(account_id)` 返回 `{ok, account_id, profile, editable_fields, message?}`。`profile` 为完整规范资料，字段为 `public_id`、`display_name`、`avatar`、`school`、`college`、`major`、`grade`、`bio`。`public_id` 必须为既有对外稳定 ID；内部账号键、昵称或令牌不会替代它。头像使用已加载的资源路径或由服务适配器缓存的持久图片文件；远程下载由适配器负责，无法加载时回退默认头像。
- `editable_fields` 只包含允许修改的字段及其现有规则，例如 `display_name: {max_length: ...}`。没有权限项即只读。头像须提供 `avatar: {extensions: [...], max_bytes: ...}` 后才开放文件选择，避免前端自定业务限制。`public_id`、登录身份、角色、认证状态不参与编辑。
- `save_profile(account_id, patch, avatar_file)` 接收有改动的可编辑字段和可选头像本地源文件。适配器须完成授权、上传和持久化，再返回 `{ok: true, persisted: true, account_id, profile, editable_fields}`；头像返回持久引用，不能回传所选临时源路径作为保存结果。失败返回 `{ok: false, message}` 并保留草稿。前端不会乐观替换已提交资料，会拦截重复提交和过期响应。页面离开清理未提交草稿；已经提交的请求由统一状态层完成，不依赖窗口生存期。
- `request_account(account_id)` 返回 `{ok, account_id, login_method?, masked_email?, masked_phone?, message?}`；只展示明确脱敏的联系方式，不读取密码或令牌。可选 `open_account_settings(account_id)` / `begin_login()` 打开宿主既有账号流程；认证结果由宿主通过 `use_provider` 同步。`logout(account_id)` 只有返回匹配账号的成功结果后才清除当前会话，失败保留状态。
- 好友请求仍为 `CollectionStore.search_friends` / 既有 `request_friends`；没有另建好友关系、管理规则或聊天功能。新入口不更改收藏库存、想要标记、赠送规则、题库授权和学习记录。
