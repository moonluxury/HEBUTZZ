【内容与尺寸】
01 火箭 / ROCKET：启航与理想。
02 人造卫星 / SATELLITE：探索与连接。
03 空间站 / SPACE STATION：协作与共同进步。
04 宇航员 / ASTRONAUT：勇气与求知。
05 空天飞机 / SPACEPLANE：工程创新与突破。
06 射电望远镜 / RADIO TELESCOPE：科学研究与未知探索。
07 环状行星 / RINGED PLANET：宇宙、未来与无限可能。

卡面统一为 1024×1536 像素，2:3 竖版，RGB/sRGB，圆角外侧透明。
七张卡使用完全相同的边框、品牌位置、编号位置和名称栏。
无字插画为 1145×1374 像素，原始完整构图单独保存。

【分层文件】
01_独立卡面：七张可直接使用的完整 PNG。
02_插画：七张无文字、无边框的插画 PNG；主体与环境位于同一插画层。
03_通用模板：标准卡片模板预览、底卡、透明卡框，卡框同时提供可编辑 SVG 与 PNG。
04_独立文字层：每张卡独立的透明文字 PNG 和可编辑 SVG；00 是空白模板的文字占位层。
05_Godot组件：共用 Card.tscn / Card.gd、CardBack.tscn / CardBack.gd，七个独立卡片场景，Gallery 总览场景。
06_制作源文件：七份完整分层 SVG、卡片数据 cards.json、合成脚本和图像生成提示词。
07_共用卡背：1024×1536 的完整卡背 PNG、正背对照、无字插画、底卡、透明卡框、独立文字、分层 SVG。

卡背按原说明重做为休闲网页游戏集卡风格：浅蓝、淡紫、奶油黄色，简洁卡通环状星球、卷云和飘带铭牌。
外框沿用正面的奶油白与深蓝描边，文字为深蓝色，使用轻度手绘、柔和渐变与局部高光。
中央星球与云纹图案由七张卡共用，不含卡片编号、主题名称或其他区分不同卡面的信息。
卡背与正面采用相同的外轮廓和圆角，圆角外部透明。
card_back_layered.svg 的文字可编辑；星球、云纹、飘带与背景共同位于插画层，并非逐个天体拆分。
card_back_art.png 是原始无字插画；card_back_art_layer.png 是已对齐 1024×1536 画布的插画层。
合成顺序：card_back_base.png → card_back_art_layer.png → card_back_frame.png → card_back_text.png。
使用 06_制作源文件/compose_card_back.cjs 可重新排版卡背；提示词见 card_back_prompts.json。

完整 SVG 按“底卡 / 无字插画 / 统一卡框 / 文字”分组；插画内嵌于独立图像层。
每份完整 SVG 可以单独移动和打开。文字仍是可编辑文本，不是描边路径。

【Godot 使用】
可直接用 Godot 4 打开本文件夹根目录 project.godot，运行查看七张卡片和共用卡背。
单张场景位于 05_Godot组件/cards；通用组件为 05_Godot组件/Card.tscn。
实例化后，card_index 为 0—6，对应编号 01—07。
将 show_back 设为 true 显示共用卡背，设回 false 恢复该卡原来的正面。
也可直接实例化 CardBack.tscn；其中 brand_text / series_text 是可编辑的背面文字。
此组件提供正背显示切换，动画可由项目自行添加。
title_override、english_override 可以修改显示文字。
illustration_override 可以替换插画。
chinese_font_override 可以指定项目自有的中文字体资源。
use_raster_text 默认为 false，使用真实 Label 节点；改为 true 时使用透明文字 PNG，以固定文字外观。
当使用文字 PNG 时，title_override / english_override 不改变贴图内容。
调整根 Control 的尺寸会等比缩放整张卡片，保持 2:3 比例，并在剩余空间中居中。

集成到已有项目时，将 02_插画、03_通用模板、04_独立文字层、05_Godot组件、06_制作源文件、07_共用卡背
这六个同级文件夹复制到一个统一资源目录中，保持相对结构即可；不要复制本示例的 project.godot。
脚本按自身位置寻找资源，不依赖本机 E 盘路径。
cards.json 是可读数据；导出已有游戏时，请将该 JSON 加入 Godot 的非资源导出包含规则。
完整 SVG 用于设计软件编辑；Godot 场景使用 PNG 和真实 Label，不依赖 Godot 对 SVG 文字的支持。

【字体与画风】
中文排版使用微软雅黑，英文使用 Arial；字体文件未随包复制。
在其他系统编辑 SVG / 使用真实 Label 时，可选择思源黑体、Noto Sans CJK SC 或自有字体替代。
成品 PNG 与透明文字 PNG 已固定外观，不需要另外安装字体。
深蓝主色 #244D70；卡框采用奶油白、浅蓝描边和轻微高光。
七张插画以复古休闲网页游戏的 2D 收藏卡氛围为方向，采用统一线条和柔和手绘色彩。
插画由内置 image_gen 生成；火箭先完成画风校正，其余六张据此统一画风。具体提示词见 imagegen_prompts.json。
