# 雪原极光制作进度

## 当前状态

当前为 v3 连续斜边重建版。针对上次修复仍存在的偏折，已用单一直线重新处理主体左侧边缘及后景轨道的遮挡。该窄带内允许修正 Alpha，带外保持原始透明轮廓。正式文件位于 `final/`，源文件位于 `source/`；下方阶段记录为按时间保留的历史，不替代当前修复说明。

## 已确认的输入

- 使用 `HEBUT卡背_团队Logo版_20261019/02_视觉素材/team_logo.png` 的原始透明 PNG。
- 源图为 1254×1254 RGBA；带学校名称的横版大图含棋盘格底，未作为蒙版来源。
- 当前工作目录中的 SVG 为学校字标及其他图标，未发现这枚 H／火箭团队标志的独立矢量原件。
- 已有「旧日航天」分区数据可用于定位部件，但本次重新从原始 Alpha 建立母版，不沿用做旧或透明度归一化处理。

## 已定参数

- 画布 2048×2048；有效图形宽度 1516，约 74%。
- 用 Alpha≥8 定位有效裁框，框内原始像素和 Alpha 保留；只裁掉四周近乎不可见的远处残留与空白。
- 所有效果只改变轮廓内 RGB；透明核心的 Alpha 始终直接取自同尺寸母版。
- 色板与效果参数集中在 `source/config.json`；随机种子固定。
